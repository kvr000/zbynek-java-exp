Quarkus secure field experiment

Pages

  • /login - dummy login, super / super
  • /login/roles - switch roles of the current session, shows the Bearer token
  • /logout - clear the session cookie

Ticket API

  • GET /api/ticket - list
  • GET /api/ticket/1 - single ticket (increments views)
  • POST /api/ticket, PUT /api/ticket/{id}, PATCH /api/ticket/{id} - use the console below
FieldReadWrite
idallnobody (server assigned)
systemsuper, adminsuper, admin
titleallsuper, admin, user
viewssuper, adminsuper (counter incremented by GET /{id})
descriptionsuper, admin, usersuper, admin, user

Reading the API requires any of super/admin/user/guest, writing requires super/admin/user. Sending a field you cannot write returns 403, unless the value is unchanged. PUT resets writable fields missing in the body, PATCH is JSON merge patch.
